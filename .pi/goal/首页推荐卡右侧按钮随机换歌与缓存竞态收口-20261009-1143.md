# 首页推荐卡右侧按钮随机换歌与缓存竞态收口

## Goal
让首页“随机歌曲”标题上方推荐卡的右侧圆形按钮仅更换展示歌曲（获取新推荐批次并展示首曲），不启动或干扰播放器状态；用户点击卡片主体仍播放当前展示歌曲及整批推荐；同时完善推荐歌曲的异步发布与缓存写入顺序控制，并通过单元测试与组件测试全面验证。

## Acceptance criteria
1. **推荐卡交互分离**：`lib/features/home/home_screen.dart` 中推荐卡右侧按钮具备独立交互，点击触发换歌（`shuffle`），不触发卡片主体播放；在播放器空闲、暂停或播放中时刷新均不影响原播放队列、当前曲目及播放状态；卡片主体点击仍按原逻辑播放当前卡片展示的第一首歌曲及对应推荐批次。
2. **状态与缓存竞态收口**：`lib/core/providers.dart` 中的推荐歌曲 Notifier 正确处理 generation 锁、跨 await 状态检查及同 `serverId` 缓存写入顺序，防止在切库、组件重建或销毁时旧响应污染当前 UI 或覆盖最新缓存。
3. **定向测试覆盖**：
   - `test/daily_recommend_shuffle_test.dart` 完整覆盖 HTTP 竞态、同库/切库缓存待写、重建与销毁等场景，断言同键缓存与状态发布一致性。
   - `test/home_daily_card_widget_test.dart` 覆盖右侧按钮只换歌不播放（断言无播放相关调用）、空闲/暂停/播放中状态保持、卡片主体播放当前批次等交互场景。
4. **代码规范与自动化验证通过**：
   - `dart format --output=none --set-exit-if-changed lib/core/providers.dart lib/features/home/home_screen.dart test/daily_recommend_shuffle_test.dart test/home_daily_card_widget_test.dart`
   - `flutter analyze --no-pub lib/core/providers.dart lib/features/home/home_screen.dart test/daily_recommend_shuffle_test.dart test/home_daily_card_widget_test.dart`
   - `flutter test --no-pub test/daily_recommend_shuffle_test.dart test/home_daily_card_widget_test.dart`
