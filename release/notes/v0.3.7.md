【正式版】v0.3.7

【本次更新】
• 设置 → 关于 里的「显示反馈悬浮球」已改成悬浮球的具体设置：
  · 悬浮球样式：小把手 / 球体贴边 / 隐藏；
  · 唤醒手势：双指长按 / 三指上滑 / 双指双击，可同时开启，默认全部关闭。
• 「隐藏」等于原来的关闭：不显示任何悬浮入口，仍可从 设置 → 关于 → 问题反馈 打开反馈面板改回。
• 反馈面板内的「设置 → 灵感球 / 唤醒方式」与新的应用设置是同一份数据，在面板里改也会同步到应用设置。
• 内置反馈组件升级到 Feedback 0.8.4；应用其他部分与 0.3.6 一致，没有其他界面或功能变化。

【如何更新】
• 打开 设置 → 关于 → 检查更新；或从 Release 页面下载对应平台的安装包。
• 0.3.5、0.3.6 以及测试渠道的 0.3.6-beta.1 用户都会收到本版本更新。

【说明】
• 如果你之前在反馈面板里单独设置过悬浮球样式或唤醒手势，升级后这些旧偏好不会迁移，会从「小把手 / 全部关闭」开始，请在新设置里重新选择。
• 「隐藏」时不会显示悬浮入口，唤醒手势也不会触发。
• 「一键已读」等反馈面板能力依赖反馈服务端 0.8.2 及以上；当前线上服务已支持，无需额外操作。
