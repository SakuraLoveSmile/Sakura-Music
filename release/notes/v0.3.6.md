【正式版】v0.3.6

【本次更新】
• 内置反馈组件升级到 Feedback 0.8.3，反馈面板「我的反馈」带来一批体验改进：
  · 新增「一键已读」：一次清除当前应用的未读回复，列表随之刷新；
  · 灵感球待机样式新增「隐藏」：在反馈面板「设置」→「灵感球」选择「隐藏」后不再显示悬浮入口，仍可从 设置 → 关于 → 问题反馈 打开面板改回；
  · 状态颜色更明确：待处理（琥珀）、待补充（蓝）、等待回复（紫）、已解决（绿）；
  · 反馈入口不再显示未读数字角标，未读仍在列表内以「未读」标签提示。
• 应用其他部分与 0.3.5 一致，没有界面或功能变化。

【如何更新】
• 打开 设置 → 关于 → 检查更新；或从 Release 页面下载对应平台的安装包。
• 上一版测试渠道的 0.3.6-beta.1 用户会收到本正式版更新；正式版用户从 0.3.5 升级。

【说明】
• 「一键已读」需要反馈服务端 0.8.2 及以上；当前线上服务已支持，无需额外操作。
• 反馈组件 0.8.3 的其余改动在 Web 端截图（保留页面样式、失败时保护草稿），不影响本客户端。
