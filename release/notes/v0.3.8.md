【正式版】v0.3.8

【本次更新】
• 内置反馈组件升级到 Feedback 0.9.0（包含 0.8.5、0.8.6 的修复）：
  · 「悬浮球样式」选「隐藏」时，只隐藏闲置（收起）后的悬浮入口；已开启的唤醒手势仍可唤醒完整球继续使用，唤醒后再次闲置会重新隐藏；
  · 悬浮球待机背景会更及时地跟随当前画面更新，并修复切换页面后残留旧背景的问题。
• 应用其他部分与 0.3.7 一致，没有其他界面或功能变化。

【如何更新】
• 打开 设置 → 关于 → 检查更新；或从 Release 页面下载对应平台的安装包。
• 0.3.5、0.3.6、0.3.7 以及测试渠道用户都会收到本版本更新。

【说明】
• 「隐藏」不再是完全关闭：选「隐藏」时，完整悬浮球在启动或唤醒后会先显示，闲置 5 秒后才隐藏；如不希望被手势唤醒，请保持「唤醒手势」全部关闭。
• 「隐藏」时仍可从 设置 → 关于 → 问题反馈 打开反馈面板，把悬浮球样式改回「小把手」或「球体贴边」。
• 「我的反馈」「一键已读」等面板能力依赖反馈服务端；线上服务已升级，无需额外操作。
